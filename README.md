Password Manager
The program can save passwords and generate random ones.
This was mainly a programming exercise, not a real secure password manager (obviously).
What it does
 • Add a username and password
 • Save account information
 • View saved accounts
 • Generate random passwords
 • Store the information in a local file

How to run
[python password_manager.py](./05_password_manager.py)

About this project
I made this while I was getting more comfortable with Python and wanted to try using few different things together. (dictionaries, files, and the random module.)
